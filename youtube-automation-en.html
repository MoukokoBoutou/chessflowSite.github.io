Internal ChessFlow tool

ChessFlow
Automation

ChessFlow Automation generates short chess-puzzle videos and publishes them to ChessFlow’s official YouTube channel.

1. How the application works

The tool selects a chess puzzle, automatically produces a vertical video with ChessFlow animations and branding, and prepares its title and description. It is operated exclusively by ChessFlow and is not offered to public users.

2. Use of YouTube

ChessFlow Automation uses the YouTube Data API to upload generated videos to the authorized channel. The application only requests the youtube.upload permission required for this purpose. It does not request access to email, contacts, Google Drive files, or other Google Account data.

3. Authorization and security

Only the owner of the ChessFlow channel can authorize the application. The resulting OAuth token is stored as an encrypted secret in ChessFlow’s private GitHub Actions environment; it is never published in source code or shared with third parties.

4. Access control

The account owner can revoke access at any time through their Google Account connections. Revocation immediately prevents any further upload by the automation.

5. Privacy and contact

Details about data use, retention, and deletion are available in the ChessFlow Privacy Policy. For questions, contact chessflowof@gmail.com.
